# bentossell

Ben Tossell's personal site, presented as an expandable personal tree.

- Keep the site dependency-free and statically hosted.
- Follow the `v2` frame in `~/tldraw/site.tldraw`.
- Keep the interface compact, quiet, and information-dense.
- Use Shantell Sans for handwritten headings and mono text elsewhere.
- Keep tree connectors continuous. Keep Ben's Bites and investor collapsed by default.
- Open every link in a new tab.
- Store all visible content and links in `content.md`.
- Run `npm run dev` and test desktop and mobile before committing UI changes.
